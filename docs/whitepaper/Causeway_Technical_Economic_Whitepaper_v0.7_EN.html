01 / Executive Summary

Executive Summary

Causeway is an AI trading-intelligence and verifiable reasoning layer for prediction markets. It organizes real Polymarket market data, AI reasoning, risk previews, order previews, Arc proof, and Signal Track Record into an auditable workflow.

Version 0.7 upgrades the long-term vision from single-model judgment to Causeway’s own Swarm Prediction Engine: a system that builds parallel market worlds, coordinates role-specialized agents, simulates event propagation, and turns the output into tradable, verifiable, reviewable market-intelligence objects.

02 / Market Context: Prediction Markets as Probability Infrastructure

Market Context: Prediction Markets as Probability Infrastructure

Prediction markets are evolving from event-betting interfaces into probability data layers for politics, macro events, sports, corporate events, and on-chain activity. Prices are not only trades; they are public signals that aggregate dispersed information in real time.

As markets scale, users no longer merely need discovery. They need help deciding which prices already reflect information, which related markets lag, and which signals are only liquidity noise.

03 / Problem: Why Prediction Markets Still Lack an Intelligence Layer

Problem: Why Prediction Markets Still Lack an Intelligence Layer

Markets are networks, but most interfaces still present lists. AI can explain text, but often lacks verifiable input snapshots, reasoning traces, order previews, and post-event performance records.

Causeway addresses the full chain from event to market network, from probability to edge, from reasoning to user confirmation, and from pre-event record to post-event audit.

04 / Academic Foundation and Value Calculation Framework

Academic Foundation and Value Calculation Framework

Prediction-market research shows that binary contract prices can approximate event probabilities under ideal conditions, but real markets contain spreads, fees, slippage, limits, source risk, and resolution ambiguity. Causeway therefore separates research probability from executable probability.

Value does not come from “AI thinks it is more likely.” It comes from positive edgeNet after transaction friction, source uncertainty, rule risk, and portfolio correlation are deducted.

p_mid = (bestBid + bestAsk) / 2p_exec_yes = ask_yes, p_exec_no = ask_noq_ai = calibratedForecast(event | marketSnapshot, sourceObjects, reasoningTrace)rawEdge_mid = q_ai - p_mid

Separate midpoint probability from executable price to avoid overstating edge.

EV_token_yes = q_ai * 1 + (1 - q_ai) * 0 - ask_yes - cost_per_tokenROI_yes = EV_token_yes / ask_yesedgeNet = q_ai - ask_yes - feeRate - slippageBps - ruleRiskHaircut - sourceRiskHaircutBUY only if edgeNet > minEdge, depthAtLimit > targetSize, timeToClose > minWindow

Only edgeNet that remains positive after costs, slippage, rule risk, and source risk should enter trade preview.

q_adj = clamp(0.5 + confidence * (q_ai - 0.5), 0.01, 0.99)b = (1 - p_exec) / p_execkellyFull = (b * q_adj - (1 - q_adj)) / b = (q_adj - p_exec) / (1 - p_exec)sizeUsd = bankroll * min(max(0, lambda * kellyFull), capMarket, capPortfolio, capCorrelation)

Conservative Kelly shrinks model probability toward 50% and caps sizing by capacity, correlation, and budget.

Underround: Σ ask_i + fees + slippage < 1profitFloor_buyBasket = 1 - Σ ask_i - fees - slippage - settlementRiskIf event B implies event A, then P(B) ≤ P(A)semanticEdge = violation * relationConfidence * min(liquidityScore_A, liquidityScore_B)

Mutually exhaustive baskets and semantic implication help detect inconsistency, but execution depth and rule compatibility must be verified.

Brier_mean = mean((q_ai - y)^2)LogLoss_mean = mean(-[y * ln(q_ai + eps) + (1 - y) * ln(1 - q_ai + eps)])CalibrationError = Σ_k n_k / N * |mean(q_ai in bucket k) - mean(y in bucket k)|signalScore = z(edgeNet) + z(confidence) + z(liquidity) - z(spreadRisk) - z(sourceRisk) - z(correlationRisk)

Long-term evaluation must include calibration, log loss, Brier score, and non-executed opportunity performance, not only PnL.

05 / Product Definition

Product Definition

Causeway is a prediction-market Trader Intelligence Layer. Its core output is not a chat answer but a market intelligence object: root market, candidate markets, semantic relations, AI fair odds, market odds, edgeNet, risk explanations, order preview, Arc proof, and track record.

The default boundary is user governance: AI expands the thesis and previews risk; the user keeps final confirmation and control of funds.

06 / What We Have Solved

What We Have Solved

Causeway separates market titles from real tradable outcome tokens and models events, markets, outcomes, CLOB token IDs, prices, books, and liquidity.

Arc proof can anchor reasoning-trace hashes on Arc; Arc USDC premium can verify membership through payment intents and Transfer logs.

Architecture and Data Model

08 / AI Trader Intelligence: From Probability to Action Preview

AI Trader Intelligence: From Probability to Action Preview

A mature system should not only output BUY. It must be able to return WATCH, VERIFY FIRST, or AVOID. No Trade is a capability because it shows awareness of liquidity, sources, rules, and portfolio risk.

Position sizing comes from edgeNet, confidence, order-book depth, spread, budget, correlation, and conservative Kelly, not from a fixed amount.

09 / Arc Proof: Verifiable AI Reasoning Records

Arc Proof: Verifiable AI Reasoning Records

Prediction markets verify today’s judgment against future outcomes. AI signals must therefore prove they existed before resolution. Arc proof anchors the reasoning-trace hash on-chain, reducing silent rewriting risk.

Arc does not replace the Polymarket trading path. It is a low-cost, stablecoin-native, EVM-compatible audit layer.

12 / Swarm Prediction Engine: From Parallel Market Worlds to Predicting Anything

Swarm Prediction Engine: From Parallel Market Worlds to Predicting Anything

Causeway’s long-term goal is not to make a single AI judge one market once. It is to build a swarm prediction engine native to prediction markets. Starting from a real event, the system constructs parallel market worlds and lets role-specialized agents debate evidence, counterexamples, probability, risk, and execution boundaries.

A parallel market world is not generic storytelling. It is prediction-market-native simulation: each world must explain how an event travels through the market graph, which odds move, which edge appears, which risk activates, and what verifiable record remains.

The engine compresses agent debate into structured market-intelligence objects: scenario tree, affected markets, probability shift, AI fair odds, edgeNet, risk flags, suggested size, Arc proof hash, and track record entry.
