# Causeway 开发文档

本目录存放 Causeway 新版开发文档，用于和旧版 ScriptFlow 文档区分。

建议阅读顺序：

1. `causeway-product-requirements.md`：产品范围、主流程和一期完成定义。
2. `causeway-polymarket-integration-and-trading.md`：Polymarket 数据、盘口、SDK 和真实下单约束。
3. `causeway-ai-inference-design.md`：AI 推演输入、输出、层数和缓存设计。
4. `causeway-database-schema.md`：数据库表、索引、迁移顺序和 Causeway 版 Prisma 口径。
5. `causeway-api-contract.md`：前后端接口契约。
6. `causeway-backend-development.md`：后端模块、任务、缓存和风控。
7. `causeway-frontend-development.md`：前端路由、页面、状态和交互。
8. `causeway-development-roadmap.md`：一期 P0-P5 开发里程碑和验收标准。
9. `causeway-real-order-spike.md`：真实下单技术 Spike 方案和验收标准。
